Layer 2 · NL2-KK

CI/CD Quickstart (Pure Python 3.10+)

git clone https://github.com/alpalbayrak91-boop/leakspec-cli.git
cd leakspec-cli
pip install .
leakspec benchmark --n-rows 2000
leakspec scan --csv data/feature_store_d10.csv --target-col target_ret --time-col ts --alpha 0.01 --json-out reports/receipt.json --sarif-out reports/leakspec.sarif

Exit codes: 0 = CAUSAL_CLEAN, 2 = LEAK_DETECTED (blocks PR merge), 1 = CLI/CSV input error.
